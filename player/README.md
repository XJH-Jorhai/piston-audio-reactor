# 开凿 · Listening Room

独立音乐播放器实验，分支 `feature/music-player`，基于整站定格标签 `v1.0.0`。生成器和三个定格可视化入口继续保留。

- 左侧保留长廊“播放器视角”及真实音频频谱联动，默认 64 路，38% → 0%；移除底部频谱柱状 UI。
- 使用音源内嵌的原始 IV 封面，整页模糊加暗背景，右侧清晰浮层封面。
- 自定义播放/暂停、点击或键盘拖动进度、前后 10 秒、音量、静音、单曲循环、全屏以及系统 Media Session 控制。
- 本地音频读取 ID3 歌名、作者、专辑、封面和附带歌词；支持单独更换封面。没有内嵌封面时使用本地音轨插画。
- 支持 LRC 同步歌词、重复时间标记、全局 offset、点击歌词跳转；也可显示普通文本歌词。默认音源没有附带歌词，界面显示待载入状态。
- 播放设置包含路数、强度、平滑、行程两端、响应曲线和歌曲信息；数值设置保存在此浏览器。
- 鼠标拖动自由旋转、Shift/右键平移、滚轮缩放；左下角可恢复播放器视角。窄屏在同一角度上调整构图。
- 快捷键 Space 播放/暂停、左右方向键前后 5 秒；输入框和按钮保持原生键盘操作。

## 开发与发布

在此分支根目录运行 `npm run dev`，打开 `http://127.0.0.1:4173/player/`。

```sh
npm run test:player
npm run build
```

`player/` 为完整独立页面，可整体部署到静态目录；构建时也会复制到 `dist/player/`。预览路径为 `experiments/music-player/`，与定格站点分开。链接 `?autoplay=0` 可关闭进入时自动播放尝试。音频和图片导入均在本机完成。

素材来源见 [CREDITS.md](CREDITS.md)。原始场景核心从定格版本的长廊渲染器复制到 `engine/`，保留几何与深度关系。
