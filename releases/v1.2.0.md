# v1.2.0 · 播放器成为主线

以六曲长廊定格版 `v1.1.0` 为基线，将播放器合入 `main` 并作为仓库首页入口。

- 播放器加入长廊 / 线性 / 横卧可选样式，默认长廊构图保持不变。
- 只切换渲染器，播放进度、暂停状态、音量、六首曲目、封面、歌词和频谱参数连续保留，不重新载入音源。
- 每种样式保留本次会话中自由调整的相机；恢复按钮回到当前样式默认构图。4–64 路及行程映射共用当前设置。
- 线性和横卧渲染器取自本项目定格工具，仅适配素材路径；机械几何和活塞伸缩关系不变。
- 六曲长廊定格预览 `experiments/music-player/` 不改动，正式标签 `v1.1.0` 与原播放器源码标签 `v0.1.0-player.3` 均保留。
- 原三版可视化工具完整归档到 `visualizer/`，仍能同页切换；旧横卧 / 长廊入口转到归档对应页面。
- 旧的跨分支播放器预览发布脚本停用。后续以 `main` 中的 `player/` 为准，README、来源与回退说明同步更新。

验证：49 项自动检查通过；桌面 1440×900 和手机 390×844 均无横向或纵向页面溢出；WebGL2 与 CPU 回退均检查新增样式。浏览器中在音频播放时连续切换四次，播放位置持续前进、始终保持播放、音量及同步歌词不变。另检查主页进入播放器及归档入口。

运行：`npm run dev` 后打开根路径；构建：`npm run build`，完整输出为 `dist/`。播放器可独立部署整个 `player/` 目录。无需音乐平台账号或后端歌曲存储。
