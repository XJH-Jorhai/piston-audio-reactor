# 横卧阵列试验 · Piston Audio Reactor

从透视长廊版本 v0.2.0-corridor.1 分出的独立展示路线。将原版开凿机整体旋转 90° 横卧，沿长轴排列成三条平行升降轨道；保留一格真实活塞行程。路数可在 4–64 之间逐路调节，默认 8 路，提供 8/16/32/64 路快捷切换。

## 视角与机械关系

默认侧俯视，另有正俯视按钮。正俯视是从阵列长边正面斜向看入，视线水平分量垂直于排列方向，保留 52° 俯角；不是垂直顶视。两种视角均采用正交投影，远端机器不会缩小。窄屏调整画面排列角度以容纳完整阵列。可通过 ?view=top 直接打开正俯视，?view=side 打开侧俯视。

高响度时中央两格躯干向上抬起，两侧手臂同步向下收回。活塞底座与南瓜固定，仅活塞臂、顶板与对应铁块升降。南瓜雕刻面随整个装置旋转朝上。所有材质保持随物体旋转的原有朝向。铁块侧列稍作暗化，地面阴影随实际高度变化，以加强三条轨道的层次。

支持自由环绕观察：默认拖动旋转，水平可绕满 360°，俯角可从 −89° 到 89°。Shift/右键拖动平移，或启用“平移”按钮后直接拖动。滚轮或按钮缩放，触屏单指旋转、双指缩放和平移。选中画布后方向键旋转，Shift 加方向键平移，+/− 缩放，Home 适配。旋转期间保持当前缩放和平移，聚焦单台后绕该机器旋转。

“适配”或双击画布以当前角度查看全部阵列，“单台”查看局部，点击频段选择对应机器。拖动后切换为“自由”状态；点击正俯视/侧俯视恢复该预设的角度与构图。窗口尺寸改变会保留自由视角的角度。所有相机操作保留音频播放和响应参数。

“频谱路数”滑杆支持 4–64 的整数，切换路数时保留当前观察角度，清除单台聚焦并自动适配全部机器，音频继续播放。?count=16 可直接打开 16 路；路数会同步到当前地址。每次切换都重新分配频谱、构建完整底座与轨道，不通过拉伸原有模型补足数量。

## 音频映射

FFT 大小 4096，40 Hz–16 kHz 按所选路数分成对应数量的对数频段。每个频段对线性功率求平均，再将 RMS 频谱响度直接映射到机械位置，不使用周期载波、正弦振荡或预制循环。高电平使中央躯干升起，左右铁块反向联动；机械位置平滑抑制抖动。低、中、高频颜色按路数等比例分配，16 路以上频段条改为编号显示，频率范围保留在悬浮提示中；频谱柱宽和间距随路数与容器宽度自适应，窄屏也完整显示全部通道。

默认低电平/静音端点为生成器进度 32%，高电平端点为进度 0%（中央躯干全伸出）。在两端的真实机械位移之间按归一化电平插值，默认线性；不再围绕中位向两侧映射，也不再经过旧的低电平反向收回段。行程始终限制在配置的两端之间，所有活塞仍只移动 0–1 格。输入电平读取时域 RMS 并显示为 dBFS。

“电平 → 行程”面板可调整低电平姿态、高电平姿态（0–50% 的生成器进度）和响应曲线（0.25–4）。0% 为中央全伸出，50% 为全收回。曲线为 1 时线性；小于 1 时弱信号更明显，大于 1 时更突出强信号。端点可以互换以反转方向，也可设成相同姿态。参数自动保存到当前浏览器的 localStorage，刷新后继续生效；“恢复 32 → 0”恢复默认映射。

默认音乐 Assumptions / Sam Gellaitry。浏览器允许时尝试自动播放，否则点击“启动声场”开始。支持本地音频、暂停、进度、音量、响应强度、平滑度和映射端点。所有音频分析均在浏览器本机完成，导入音频不会上传。

## 记录好的视角

用户提供的 6 个视角现已成为页面按钮：默认-64路、默认-8路、默认-16路、默认-32路、方形小视角、开凿者视角。名称保留记录时的文字，切换只恢复相机，不改变当前频谱路数或电平映射参数。按现有阵列重新定位整体中心或聚焦台，保留记录的角度和放大倍率；换路数后继续使用选中的视角。自由拖动或使用其他相机控制后退出快捷视角状态。

可以用 `?count=64&preset=saved-1` 直接打开第一个视角，`saved-2` 至 `saved-6` 对应其余记录。横卧版隐藏保存视角的开发者面板，电平→行程面板继续保留。线性版独立保留开发者记录能力。

## 视角记录格式（开发者）

在线性版可展开页面下方的“开发者 · 视角记录”。调整画面后输入可选名称，点击“记录当前视角”；可积累多条，分别载入、导出或移除，也能通过“全部导出 JSON”打包保存。

记录包含相机角度（弧度）、真实目标点与旋转枢轴、缩放、投影中心、平移、原画幅、路数、频段选择及当前响应/映射参数。载入会恢复这些参数并继续音频播放。相同画幅精确恢复；其他画幅按原构图等比缩放。自由视角在画幅往返改变时保留参考构图。

记录列表自动保存在当前浏览器，可用“导入 JSON”带到另一个浏览器。文件使用 `format: piston-audio-reactor.camera-views`、`version: 1` 和 `views` 数组；支持最多 200 条，单文件最多 2 MB，导入前完整校验。重复标识的记录跳过以便重复导入。同一文件可发给开发者复用构图。

场景、频谱条以及场景角落不再显示 01、02 等通道序号；频率提示与可访问的通道选择名称继续可用。

## 运行与验证

Node.js 20+，无外部运行时依赖：

    npm run dev
    npm test
    npm run build

开发服务器默认 http://127.0.0.1:4173/，支持音频 Range 请求。dist/ 可部署为静态网站。

所有机器共享 WebGL2 纹理图集和深度缓冲；提供逐像素深度的 CPU 回退，可通过 ?renderer=cpu 手动查看。两个后端均绘制旋转后的六面几何，使用相同的正交相机和深度关系。

自动验证覆盖 4–64 台布局与频谱分配、刚体旋转、固定底座、活塞臂完全收回、反向升降、预设/自由相机的全行程取景与裁剪范围、频谱映射和静音姿态。

## 三版连续切换

顶部“线性版 / 横卧版 / 长廊版”在当前标签页内切换。共用同一个 audio 元素、AudioContext、音源节点及分析器，保留进度、暂停、音量、播放速率及本地导入音源；不会重新开始音乐。浏览器前进/后退同样连续播放。每个版本的构图和响应参数在本次页面会话中保留，路数随切换带入。

完整的跨版本本地预览从 main 工作目录运行 npm run dev，三个入口及其 src/bootstrap.js、src/audio-session.js 必须一同部署。各实验分支仍保留独立几何、相机和发布快照；直接进入任一正式入口都可开始同页切换。
