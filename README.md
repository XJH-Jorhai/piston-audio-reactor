# 透视长廊试验 · Piston Audio Reactor

基于 v0.1.0-linear 的独立展示路线，采用真实透视相机。前景机器放大，后排向远处收束，保留全部 16 台机器和原始的一格机械行程。

分支：experiment/perspective-corridor。基线标签：v0.1.0-linear。
稳定版保留在 main；本分支通过单独的静态快照路径预览，不替换根站点。

- 试验 Demo：https://xjh-jorhai.github.io/piston-audio-reactor/experiments/perspective-corridor/
- 稳定线性版：https://xjh-jorhai.github.io/piston-audio-reactor/
- 频谱从左至右覆盖 40 Hz–16 kHz，分为 16 个对数频段。
- 每个频段的 RMS 频谱响度直接控制对应机器的活塞位置；左右铁块同步，中间两格铁块反向，活塞底座与南瓜固定。
- 零能量姿态为定版生成器进度 38%，沿原曲线计算侧块行程 0.5051273135、中央铁傀儡行程 0.4948726865；声音暂停后平滑返回该姿态。
- 在静止姿态两侧双向运动，机械行程严格限制在 0–1 格，不会越过底座。
- 默认音乐 Assumptions / Sam Gellaitry。浏览器允许时自动播放，受限制时点击“启动声场”或页面后开始。
- 支持本地音频文件、暂停、拖动进度、音量、响应强度、平滑度和中位姿态。
- 拖动平移、滚轮和按钮缩放；点击频段近看对应机器，“总览”回到完整 16 台阵列。默认以透视长廊展示完整阵列，窄屏自动取景；“前景”可单独聚焦第一台。
- 所有机器共用一个纹理图集和一个 WebGL2 深度缓冲，避免同时创建 16 个 WebGL 上下文；提供逐像素深度的 CPU 回退。长廊分支绘制六个面，GPU 使用真实透视除法，CPU 使用倒数深度与透视正确纹理插值；远处仅作轻度雾化。
- 所有音频处理均在浏览器本机完成。网络中不传送导入音频。

## 运行

Node.js 20+，无运行时外部依赖：

    npm run dev
    # http://127.0.0.1:4173/

    npm test
    npm run build

dist/ 为静态网页，可部署到 GitHub Pages。开发服务器支持音频 Range 请求。

## 行程映射

分析器 FFT 大小为 4096。每个频段先对线性功率求平均，再将 dB 映射到 0–1，
频谱响度直接映射到机械位置：高电平时中央铁傀儡伸出，低电平收回，左右铁块始终反向联动。
静音门控让零信号回到 38% 参考姿态，只有一个很短的机械位置平滑用于抑制抖动。
没有周期载波、正弦振荡或预制循环；每次动作都来自实际音频幅度变化。输入电平直接读取时域 RMS 并显示为 dBFS。
