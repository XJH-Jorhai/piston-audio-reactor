# 横卧阵列试验 · Piston Audio Reactor

从透视长廊版本 v0.2.0-corridor.1 分出的独立展示路线。将原版开凿机整体旋转 90° 横卧，沿长轴排列成三条平行升降轨道；保留一格真实活塞行程。路数可在 4–32 之间逐路调节，默认 8 路，提供 8/16 路快捷切换。

- 分支：experiment/lying-eight；版本：v0.3.0-lying-eight.4。
- 预览：https://xjh-jorhai.github.io/piston-audio-reactor/experiments/lying-eight/
- 16 路直达：https://xjh-jorhai.github.io/piston-audio-reactor/experiments/lying-eight/?count=16
- 稳定线性版：https://xjh-jorhai.github.io/piston-audio-reactor/
- 透视长廊版：https://xjh-jorhai.github.io/piston-audio-reactor/experiments/perspective-corridor/

## 视角与机械关系

默认侧俯视，另有正俯视按钮。正俯视是从阵列长边正面斜向看入，视线水平分量垂直于排列方向，保留 52° 俯角；不是垂直顶视。两种视角均采用正交投影，远端机器不会缩小。窄屏调整画面排列角度以容纳完整阵列。可通过 ?view=top 直接打开正俯视，?view=side 打开侧俯视。

高响度时中央两格躯干向上抬起，两侧手臂同步向下收回。活塞底座与南瓜固定，仅活塞臂、顶板与对应铁块升降。南瓜雕刻面随整个装置旋转朝上。所有材质保持随物体旋转的原有朝向。铁块侧列稍作暗化，地面阴影随实际高度变化，以加强三条轨道的层次。

支持自由环绕观察：默认拖动旋转，水平可绕满 360°，俯角可从 −89° 到 89°。Shift/右键拖动平移，或启用“平移”按钮后直接拖动。滚轮或按钮缩放，触屏单指旋转、双指缩放和平移。选中画布后方向键旋转，Shift 加方向键平移，+/− 缩放，Home 适配。旋转期间保持当前缩放和平移，聚焦单台后绕该机器旋转。

“适配”或双击画布以当前角度查看全部阵列，“单台”查看局部，点击频段选择对应机器。拖动后切换为“自由”状态；点击正俯视/侧俯视恢复该预设的角度与构图。窗口尺寸改变会保留自由视角的角度。所有相机操作保留音频播放和响应参数。

“频谱路数”滑杆支持 4–32 的整数，切换路数时保留当前观察角度，清除单台聚焦并自动适配全部机器，音频继续播放。?count=16 可直接打开 16 路；路数会同步到当前地址。每次切换都重新分配频谱、构建完整底座与轨道，不通过拉伸原有模型补足数量。

## 音频映射

FFT 大小 4096，40 Hz–16 kHz 按所选路数分成对应数量的对数频段。每个频段对线性功率求平均，再将 RMS 频谱响度直接映射到机械位置，不使用周期载波、正弦振荡或预制循环。高电平使中央躯干升起，左右铁块反向联动；机械位置平滑抑制抖动。低、中、高频颜色按路数等比例分配，16 路以上频段条改为编号显示，频率范围保留在悬浮提示中；窄屏可横向滚动频谱条。

零信号返回定版生成器进度 38% 的姿态：侧块行程 0.5051273135、中央行程 0.4948726865。行程始终限制在 0–1 格，完全收回时活塞臂消失。输入电平读取时域 RMS 并显示为 dBFS。

默认音乐 Assumptions / Sam Gellaitry。浏览器允许时尝试自动播放，否则点击“启动声场”开始。支持本地音频、暂停、进度、音量、响应强度、平滑度和静止姿态。所有音频分析均在浏览器本机完成，导入音频不会上传。

## 运行与验证

Node.js 20+，无外部运行时依赖：

    npm run dev
    npm test
    npm run build

开发服务器默认 http://127.0.0.1:4173/，支持音频 Range 请求。dist/ 可部署为静态网站。

所有机器共享 WebGL2 纹理图集和深度缓冲；提供逐像素深度的 CPU 回退，可通过 ?renderer=cpu 手动查看。两个后端均绘制旋转后的六面几何，使用相同的正交相机和深度关系。

自动验证覆盖 4–32 台布局与频谱分配、刚体旋转、固定底座、活塞臂完全收回、反向升降、预设/自由相机的全行程取景与裁剪范围、频谱映射和静音姿态。
