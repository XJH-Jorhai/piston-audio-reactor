# 网易云接入与授权凭证处理

状态：已搁置，仅保留调研记录。2026-11-02 用户决定采用固定 MP3 的纯静态 Demo，保留浏览器本地导入，不接入在线音乐账号或后端歌曲存储。下面的授权设计不是当前实施计划。核对日期：2026-11-02。定格版本 `v1.0.0` 不变。

## 先确认接入资格

网易云有官方 H5 授权、授权码换取 accessToken、刷新令牌等文档，但这不代表个人开发者取得了公开网页调用权限。

官方个人接入 FAQ 当前说明：个人场景只提供 `ncm-cli`，不直接开放平台 API；厂商接入需要联系网易云商务。因此，个人 CLI 的 appId/privateKey 不能被当成已批准的公共网页应用凭证，也不应把一个 CLI 登录会话共享给所有访客。

上线前需由网易云确认 Web 应用资格、回调地址、可用接口、音乐播放范围、额度及播放数据回传要求。申请个人 CLI 凭证本身不能完成这些确认。

## 凭证分工

| 数据 | 谁提供 | 允许出现的位置 | 保存规则 |
| --- | --- | --- | --- |
| 应用 appId | 站点运营者 / 网易云 | 前端授权参数、后端 | 公开标识，不是私钥 |
| 应用私钥及其他应用机密 | 站点运营者 / 网易云 | 独立后端的部署 Secret | 不进仓库、前端包、构建产物或日志 |
| 用户密码、账号 Cookie、个人 API Key | 访客 | 不收集 | 页面不提供填写、粘贴或上传入口 |
| 临时授权码 code | 网易云官方回调 | 授权流程中的短暂内存与官方要求的回调 URL | 校验后立即交换，不持久化 |
| 用户 accessToken | 网易云 | 当前页面内存；后端单次请求处理内存 | 不写数据库、文件、浏览器存储、Cookie、日志或缓存 |
| 用户 refreshToken | 网易云 | 后端交换结果的短暂处理内存 | 首版丢弃，不回传前端，不提供自动续期 |
| 行程、路数等数值偏好 | 访客 | 现有本地设置 | 与授权对象分离，只保存明确允许的数值字段 |

这里的“不保存”指不持久化用户凭证，不意味着请求处理过程中完全不接触凭证。页面存活期间必须临时持有 accessToken 才能代表该用户调用授权接口。

## 拟采用的流程

1. 用户点击“连接网易云”，在独立窗口进入网易云官方 H5 授权页；播放器原页面保持存活，音频无需因为整页跳转而重新加载。
2. 每次授权生成新的随机 state，绑定发起页面与短期、单次使用的授权事务。官方要求 state 为不超过 30 位的字母或数字。后端只临时维护必要的事务校验数据，不保存用户令牌。
3. 网易云在自己的域名中处理登录和用户同意。回调使用预先登记的精确 HTTPS 地址，不接受客户端提供的任意跳转目标。
4. 校验 state、事务有效期、一次性使用及窗口来源后，后端调用官方授权码交换接口。访问令牌通过 HTTPS 响应正文交给原页面，仅存于模块闭包内；不把令牌拼进 URL 或 postMessage 广播。
5. 原页面按请求发送 accessToken。后端只允许明确列出的官方操作，负责应用签名并临时转发用户令牌，不提供任意路径或任意 URL 的代理。
6. 超时、授权无效、退出或页面销毁时清除本地引用、取消待处理请求，避免迟到响应恢复已退出的授权。刷新或重新打开页面需要重新授权。

窗口间消息必须验证精确 origin、source 和事务标识，并使用明确的 targetOrigin。授权弹窗只传递流程所需的一次性结果；访问令牌不通过弹窗 URL 传输。关闭弹窗、拒绝授权、state 不匹配或超时均结束该事务。

没有确认官方支持 PKCE，不能把自建的 state 校验称为官方 PKCE。授权事务如何防重放、弹窗与浏览器隔离策略是否兼容，须在真实 Web 应用上完成联调后验收。

## 部署边界

GitHub Pages 继续托管静态播放器。应用签名与授权码交换需要独立 HTTPS 后端，不能把私钥塞入静态 JS、GitHub Pages 环境变量替换后的前端包或浏览器配置。

授权及用户接口响应必须设置 `Cache-Control: no-store`；客户端请求也禁用缓存。CDN、网关、APM、错误采集和服务端日志均需关闭请求正文 / Authorization 头采集，对授权回调的 code、state 查询参数脱敏；不能只关闭应用内的 console 日志。

回调页面不加载第三方脚本、图片或分析组件，设置 `Referrer-Policy: no-referrer`，尽快移除地址栏的 code。官方回调码会暂时出现在回调 URL 中，因此不能宣称“任何凭证永不进入 URL”。

用户令牌请求只开放指定播放器 origin；Origin 校验、限流和请求体大小限制不能代替接口权限校验。错误响应不透传官方调试正文，重定向与上游主机固定允许列表。正式部署前必须验证这些设置覆盖代理和托管平台，而非只在业务代码中声明。

内存令牌仍会受到页面脚本漏洞、恶意扩展和已失陷设备的影响。保持页面没有第三方运行时脚本、歌词及元信息使用文本输出，并部署匹配现有页面资源的 CSP；不能承诺“绝对不会泄漏”。如果未来改为后端会话 + HttpOnly Cookie，需要另行说明其会在服务端保留用户令牌，不能悄悄改变本方案的不保存约定。

## 退出与使用限制

“断开连接”清除当前页面凭证并停止相应在线请求，不等于网易云立即撤销已签发令牌。官方文档提供的用户主动撤销方式为网易云 App 的“账号与安全 → 授权管理”。未确认官方撤销接口前，不标称支持远程注销。

不保存令牌也不代表网易云不处理听歌数据。官方音乐 API 文档要求播放行为回传；获得接入资格后，需落实获批接口对应的上报要求，并在用户授权说明中解释。

播放资格、会员权益、试听和地域限制由官方接口决定，前端按返回结果展示，不能承诺所有会员曲目都可播放。

真实频谱还有独立验收条件：音乐播放地址或官方 SDK 必须允许 Web Audio 分析。跨域媒体未通过 CORS 校验时，MediaElementAudioSourceNode 输出静音；不能以假频谱替代，也不通过未获授权的音频代理绕过。若官方 Web 播放路径不支持分析，应明确显示播放能力与可视化能力的差异。

## 上线验收

- 已获得适用于此公开 Web 应用的接入权限与正式配置，而不是仅有个人 CLI 凭证。
- 两个访客并发登录互不串号；拒绝、重复回调、错误 state、过期及退出中的请求都被正确处理。
- 浏览器各类持久存储、网络缓存、服务及网关日志中无用户令牌；构建产物与仓库中无应用私钥。
- 刷新后不自动恢复用户授权；断开后迟到响应无法恢复凭证；不会使用运营者自己的账号为访客播放。
- 真实授权、搜索、歌单、播放权限、播放回传，以及 CORS / FFT 链路均已联调通过。

以上尚未验收。当前线上版本仍只使用提供的默认音源与本地导入，不显示可用的网易云登录按钮。
